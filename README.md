First 100 Fibonacci Numbers Using For Loop in Java

Project Description

This project is a Java program that generates and displays the first 100 numbers in the Fibonacci sequence using a for loop.

Objective

To demonstrate the use of loops, variables, and arithmetic operations in Java.

Programming Language

Java

How the Program Works

1. The sequence starts with 0 and 1.
2. The program adds the previous two numbers to generate the next number.
3. A for loop repeats this process 100 times.
4. The program displays all 100 Fibonacci numbers.

Concepts Used

- For Loop
- Variables
- BigInteger
- Addition
- System.out.println()

How to Run

1. Install Java Development Kit (JDK).
2. Open FibonacciSeries.java in VS Code.
3. Run the program.
4. View the output in the terminal.
